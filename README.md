# Vlaffta Hub UI — Forge 1.20.1 (47.3.0)

Свой экран вместо инвентаря в тёмно-голубо-синей «оцифрованной» теме: **Инвентарь · Хранилище · Создание · Журнал**,
валюта **Влаффта**, ограниченный инвентарь, оцифрованные подсказки предметов с 3D-моделью и окно чтения описаний.

## Сборка через GitHub
1. Новый репозиторий -> залей СОДЕРЖИМОЕ этой папки (в корне должны лежать `build.gradle` и `.github`).
2. Вкладка **Actions** -> **Build mod** -> внизу **Artifacts** -> `hubui-jar`.
3. Jar в `mods` (и на сервер, и всем игрокам).

## Инвентарь игрока
* **5 ячеек хотбара** (цифры 1–5, колесо мыши крутит только их) + **4 боковых кармана** в окне инвентаря (по 2 слева и справа от хотбара).
  Итого 9 ячеек; всё остальное лежит в **Хранилище**. Карманы на экране не видны, достать оттуда предмет можно только в окне инвентаря.
* Вместо ванильного хотбара рисуется свой на 5 ячеек: оцифрованная панель, плавно скользящее выделение, цифры-подсказки.
* Подбор с земли: если места нет — предмет остаётся лежать и появляется «Инвентарь полон». Предметы, которые «просочились»
  в скрытые ячейки (сундуки, `/give`, крафт), переносятся в свободные из 9 или выпадают на землю.
* Не действует в **творческом режиме** и у наблюдателей — там остаются ванильные инвентарь и хотбар.

## Подсказки предметов (3D) и окно чтения
* Все подсказки предметов заменены оцифрованными: голографическая рамка с **вращающейся 3D-моделью**, название «расшифровывается» цифрами,
  строки появляются по очереди, бегает сканирующая линия, рамка и акценты окрашены по редкости, на фоне прозрачные цифры.
  Подсказки предметов с картинкой (например, мешок) остаются ванильными.
* Если описание длинное (больше 9 строк), подсказка обрезается и показывает кнопку **[F] Читать полностью**.
  Наведи курсор на предмет и нажми **F** (клавиша меняется в Управлении: «Читать описание предмета полностью»), либо нажми кнопку
  «Читать полностью» в панели сведений на вкладке «Хранилище» (панель «залипает», пока мышь едет к кнопке).
* Окно чтения: крупная 3D-модель (тяни мышью, чтобы вращать; без касаний вращается сама) и полный текст крупным шрифтом
  с прокруткой (колесо, стрелки, PgUp/PgDn). Esc, E или F закрывают.
* Клавиша работает в любых окнах с предметами (сундуки и т.п.).

## Вкладки
* **Инвентарь**: модель игрока, броня, левая рука, оцифрованные полосы здоровья/брони/сытости, нижний ряд «карманы · хотбар · карманы».
* **Хранилище**: поиск (подсвечивает найденное), сортировка, сетка слотов, панель сведений. 6 рядов открыто, 7-й закрыт.
  Хранилище привязано к игроку и не теряется при смерти.
* **Создание**: поиск, 7 категорий, карточки рецептов, «Нужно / Создать ×1» (материалы из хотбара, карманов, левой руки и хранилища).
  Рецептов пока нет — заглушка. Добавляются JSON-файлами (см. ниже).
* **Журнал**: записи оставляет сюжет, игрок только читает. Непрочитанные подсвечены, вкладка пульсирует точкой.
* **Влаффта**: плашка с монетой, счётчик «накручивается», монета крутится, всплывает «+N».
* Смена вкладки «оцифровывается»: содержимое растворяется цифровыми блоками.

## Атмосфера (хоррор)
* Тема тёмная: глубокие почти чёрные фоны, приглушённые рамки, тёмная виньетка по краям, цифровой дождь и молнии тусклее,
  изредка «мерцает лампа» (короткие провалы яркости фона и свечения).
* **Тихий цифровой гул**, пока открыт хаб или окно чтения: низкий расстроенный бас с медленными биениями, тревожный полутон,
  цифровое «мерцание» и редкие потрескивания. Плавно нарастает и затухает. Громкость: ползунок звука «Окружение» и `humVolume` в конфиге.
* Звуки интерфейса в хоррор-ключе (но ненавязчиво): расстроенные колокола (малая секунда), тритон, сердцебиение при открытии,
  обратные «вдохи», глухие низкие удары, шёпот-шорох в записях журнала, искажённый зуммер отказа.

## Звуки
Все звуки сгенерированы и лежат в `assets/hubui/sounds/*.ogg` (можно заменить своими, моно): загрузка системы при открытии, выключение,
цифровой глитч при смене вкладки, расстроенные монеты, скрежет и «компиляция» при крафте, запись журнала, сканирование при появлении подсказки,
тик наведения на предмет, анализ при открытии окна чтения, тик расшифровки при прокрутке, переключение ячейки хотбара,
отказ «Инвентарь полон», передача данных при сортировке, гул (`ui_hum`, бесшовная петля 8 секунд).

## Настройки (`config/hubui-client.toml`)
`fancyTooltips` (оцифрованные подсказки), `tooltipSounds` (звук подсказки), `digitalRain` (цифровой дождь), `customHotbar` (свой хотбар на 5 ячеек),
`hum` (гул вкл/выкл), `humVolume` (громкость гула, по умолчанию 0.28).

## Команды (оператор, работают и в командных блоках)
| Команда | Что делает |
|---|---|
| `/vlaffta give <игроки> <n>` / `take` / `set` | выдать / забрать / установить Влаффты |
| `/vlaffta get <игрок>` | показать баланс |
| `/journal add <игроки> "Автор" "Заголовок" текст…` | запись в журнал (в тексте `\n` = новая строка) |
| `/journal clear <игроки>` | очистить журнал |
| `/hubstorage rows <игроки> <0..7>` | сколько рядов хранилища открыто |

## Как добавлять крафты
JSON в датапаке или ресурсах мода: `data/<namespace>/recipes/<имя>.json` (пример — `docs/example_recipe.json`):
`type` = `hubui:hub_crafting`, `category` (`clothing`, `tools`, `food`, `building`, `tech`, `misc`), `description`, `result`, `ingredients`
(`{ "item": "..." }` или `{ "tag": "..." }` + `"count"`). После правок хватает `/reload`.

## API (`HubApi`)
`addBalance`, `setBalance`, `getBalance`, `addJournalEntry(player, author, title, text)`, `setStorageRows`, `openHub`.
